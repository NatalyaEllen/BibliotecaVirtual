# Sistema símples de biblioteca

## Como Iniciar o projeto
 Rode os seguintes comandos em odem:
- `git clone https://github.com/NatalyaEllen/BibliotecaVirtual`
- `cd ./BibliotecaVirutal`
- `py -m venv ./.venv`
- `.venv\Scripts\activate`
- `pip install -r requirements.txt` 
- `python manage.py runserver`

> Pronto! O servidor já estará rodando localmente em sua máquina,  apenas inserir o endereço do memso no navegador.
